# Decisions

Every decision with its reason and what was chosen against. The organiser's repo (`CHALLENGE.md`, `RULES.md`, `data/DATA.md`) wins over anything here; where the briefing changes a rule, the decision is corrected in the same commit as the code.

Status: **proposed** means the kick-off brief's default, not yet confirmed by the team; **decided** means confirmed, with the date and the commit or PR that implements it. A decision a slice implemented in code is decided on the day it was merged (the wave 1 review, `docs/reviews/wave-1.md`). Numbers are allocated in merge order and never reused: a branch that adds a row takes the next free number when it merges `main` (D30 is unused: the audit chain merged as D36; this upkeep's test isolation and start-date cap became D44 and D45 when #32 took D41 and D42 and #33 took D43).
